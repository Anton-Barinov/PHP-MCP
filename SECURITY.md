# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting Security Issues

If you discover a potential vulnerability within PHP-MCP, please do **not** open a public issue.
Instead, submit a security advisory report directly through GitHub Advisories or reach out to the maintainer:

- Maintainer: **Anton Barinov**
- GitHub: [@Anton-Barinov](https://github.com/Anton-Barinov)

We take security seriously and will investigate, patch, and release a fix promptly.
